# 🎨 粒子文字交响曲 — Particle Text Symphony

> 输入文字，文字化作粒子之舞。鼠标即指挥棒，引领粒子翩然起舞。

## ✨ 创意亮点

这是一个将**文字视觉化 + 粒子物理 + 实时交互**融为一体的创意体验：

- **文字 → 粒子**：任何文字输入后被渲染到 Canvas，采样成数千彩色粒子，从四面八方飞入汇聚成形
- **6 种交互模式**：吸引、排斥、波浪、涡旋、散落、归位——鼠标就是你的指挥棒
- **弹簧物理系统**：每个粒子都有独立的弹簧力向其"文字位置"归位，产生自然的弹性动画
- **粒子间连线**：同色相邻粒子之间有半透明连线，增强质感与视觉层次
- **实时 FPS 显示**：右上角显示粒子数和帧率

## 🎮 操作方式

| 操作 | 效果 |
|------|------|
| 输入文字 + 回车/点击 ✨化形 | 重新生成粒子文字 |
| 鼠标靠近粒子 | 触发当前模式的交互效果 |
| 鼠标点击按住 | 增强当前模式的力度 |
| 底部按钮 / 键盘 1-6 | 切换交互模式 |

### 六种模式

| 模式 | 快捷键 | 效果 |
|------|--------|------|
| 🧲 吸引 | `1` | 粒子被鼠标吸引靠近 |
| 💨 排斥 | `2` | 粒子被鼠标推开远离 |
| 🌊 波浪 | `3` | 粒子随正弦波浪上下起伏 |
| 🌀 涡旋 | `4` | 粒子绕鼠标形成漩涡 |
| ✨ 散落 | `5` | 粒子随机飘散飞舞 |
| 🏠 归位 | `6` | 粒子缓慢回归原始文字位置 |

## 🛠 技术栈

纯原生前端技术，零依赖：

- **HTML5 Canvas** — 文字渲染与粒子绘制
- **JavaScript** — 弹簧物理引擎、粒子系统、交互逻辑
- **CSS3** — 毛玻璃 UI、响应式布局
